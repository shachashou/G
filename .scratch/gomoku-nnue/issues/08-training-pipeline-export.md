- **跨语言契约 ①**：`trainer/features.py` 是 450 维颜色绝对特征与 D4 八重对称的权威、无依赖实现；`trainer/README.md` 给出索引公式（`cell = y*15+x`，黑 `0..224` / 白 `225..449`）、8 个变换坐标表、量化前向与权重文件逐字段规范。行棋方不是特征而是选输出头。D4 下只置换特征索引，分数/WDL 标签不变。测试验证 8 个变换互异且闭合、双射、保持颜色分区与五连几何、`symmetry_table()` 与稀疏变换一致，且与 `binpack.Record.feature_indices()` 一致。
- **跨语言契约 ②**：`trainer/weights_format.py` 定义 `GMNNUE01` v1 权重文件（64 字节头 + 478,272 字节 body，整文件 478,336 字节）：魔数、版本、维度、QA=127/QB=64/score_scale=400/weight_clamp=64、FNV-1a 校验和、保留位全零；body 为 `W0/W1/W2` int8 与 `b0/b1/b2` int16。提供**纯标准库整数参考前向** `infer_int()`（可选 numpy 快路径），明确 `round_div` 半数远离零、int16 饱和语义——09 的 C++ 标量实现据此逐位对齐。测试覆盖魔数/版本/校验和/保留位/维度/权重越界拒绝、文件往返与手算前向。
- **数据集**：`dataset.py` 复用 `binpack.BinpackReader` 的 mmap；新增 `game_index_map()`（只读 flags 字节，不必为 1000 万条记录物化 Python 对象）；固定 seed 按**完整对局**划分，`assert_disjoint()` 训练前断言无对局交集；`__getitem__` 实时 D4 增广，验证集不增广。`train.py` 用显式 `collate_batch` 把纯 Python 样本堆成张量（避免 `default_collate` 把 450 维 list 转置），并在 `finally` 里关闭 mmap（Windows 文件锁）。
- **模型 / 损失**：`nnue.py` 实现 450→1024(int16 域)→ClippedReLU→15→ClippedReLU→双头 1，权重以小整数初始化 + 量化正则；两种前向同拓扑：可微浮点前向训练，`quantized=True` 用 STE 取整 + STE `round_div`，**与 `infer_int()` 逐位一致**。损失 `MSE(tanh(eval/400), tanh(score/400)) + 0.2*CE(WDL) + 0.05*量化正则`；WDL logits 由单一 eval 派生 `[-eval/T, 0, +eval/T] + wdl_bias`，`T=100`，`wdl_bias` 是**训练专用的三维类别先验、不导出**（否则单标量对称 logits 的 CE 卡在 `ln 3` 附近，实测加了它 CE 才从 0.917 降到 0.710）。
- **训练实测（GPU）**：`data/raw/bench-d4/train.binpack`（280 局 / 7208 局面，depth 4），6,580 train / 628 val，28 局整局留作验证，默认 20 epoch × 0.5s/epoch。验证损失 `0.96091 → 0.85424`（-11.1%，best @ epoch 18），CE `0.91686 → 0.70970`，`converged=True`；逐 epoch 曲线在 `weights/training_history.json` 的 `loss_curve`，最佳 checkpoint `weights/nnue_v1.pt`。
- **量化导出实测**：`weights/nnue_v1.nnue` 478,336 字节、魔数/版本/FNV-1a/维度全部回读通过、整数前向重放一致。采样 64 局面：`STE 前向 vs 整数参考 max 0.0000`（64/64 逐位一致），`float vs 整数 MAE 0.356 / max 0.978`，输出头偏置校准 `[-3, -45]`，`export_report.json` 给 09 的建议容差 `≤ 2`。`NNUEModel.from_quantized_weights()` 供 09 用导出权重重建 PyTorch 参照。
- **测试**：`engine/tests/training_tests.py` 接入 CTest。纯标准库部分（特征/D4、格式、对局划分）无需 torch 即可跑；检测到 torch 后自动追加模型 STE/整数等价、2-epoch 训练、导出回读自校验。torch 装好后 **10/10 全绿**（整套 8.2 秒）。
- **已知边界 / 交接**：① 首轮权重只用 7208 个基准局面训练，棋力尚弱，M5/M6 需用 1000 万局面数据重新训练并做胜率门控；本工单验收的是流水线闭环与收敛曲线。② 单一标量 eval 派生的 WDL 头表达能力有限，CE 依赖训练专用的 `wdl_bias`；若 M6 要提高 WDL 质量，可考虑独立三分类头（会改变 spec，需另行决策）。③ 导出时的 `b2` 校准是 PTQ 后处理，导出的权重与训练 master 权重不完全相同，因此 09 的对齐应以 `from_quantized_weights()` 重建的模型或 `infer_int()` 为参照。④ `weights/` 下产物与 `data/` 均为 gitignore，不入库。
