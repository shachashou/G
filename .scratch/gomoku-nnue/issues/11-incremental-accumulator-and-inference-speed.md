# 11: 增量累加器与推理加速

**What to build:** 用户使用新模型对弈和采集时，引擎通过第一层增量累加器减少重复计算，并提供可复查的推理和实际搜索性能数据，同时保持与全量参照一致。

**Blocked by:** 07 — 使用新模型实际对弈。

**Status:** ready-for-agent

- [ ] 对450 → 1024 → 64 → 32 → 1网络实现第一层稀疏增量更新：落子增加对应向量，撤销减去对应向量。
- [ ] 后续隐藏层和输出层正常前向；不把整网评估描述为只有向量加减。
- [ ] 内部累加采用足够宽且可逆的表示或明确状态保存，避免饱和后减法无法还原。
- [ ] 新局、局面全量同步、连续落子撤销、搜索分支回退和终局路径保持棋盘与累加器一致；非法操作不改变任何相关状态。
- [ ] 保留全量标量参照，覆盖完整对局、多种子随机合法序列、深层撤销与边界局面，增量输出符合冻结数值契约。
- [ ] 在现有目标平台接入适用的 AVX2 加速，逐局面核验标量与优化路径一致；不以近似值隐藏错误。
- [ ] 在真实引擎选点和采集路径实际启用优化，提供可确认的运行配置与后端身份。
- [ ] 在相同模型和资源配置下报告推理耗时、搜索吞吐及配对开局实际表现，区分单次推理提速与整机棋力提升。
- [ ] 性能结论基于实测，预先记录测量条件，不编造固定加速倍数；出现数值或性能回退时可明确选择参照路径。

## Verification

在模型推理文件边界、落子撤销公共行为及真实引擎搜索边界对拍。只因本工单引入优化而增加有针对性的随机序列与性能测量，避免重复运行无关训练实验。
