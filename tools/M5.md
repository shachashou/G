# M5 分阶段诊断与用户运行指南

工单 12–15 的诊断与验收阶段。先读每阶段结果再选择下一项实验；这些命令不会自动串联训练、自举或晋级。所有命令从仓库根目录执行，使用项目 `.venv`；**用户终端已激活 `.venv` 时，给用户的命令一律简写为 `python`**（运行器会把裸 `python` 固定替换为自身解释器，报告分别记录请求与实际命令）。**agent 的工具 shell 未激活 venv**：agent 侧执行需要 torch 的脚本（`train.py` / `diagnose.py` / `weight_drift.py`）仍写 `.venv\Scripts\python.exe`，否则会报 `ModuleNotFoundError: No module named 'torch'`。

## 运行约定

预计超过 5 分钟或无法可靠估时的任务由用户启动。统一使用 `tools/budget_run.py`，共用 `data/m5/budget.json`，首轮累计上限 7,200 秒。`--seconds` 是该任务的实际硬上限，不是预计耗时；若剩余预算不足以容纳整个请求则拒绝启动。启动前预留时间，结束后按整项任务实际墙钟计时结算，并行 worker 不重复收费。

每次使用新的 `--out-dir`；运行器和诊断工具都拒绝覆盖已有实验。`console.log` 保留 stdout/stderr，`run.json` 记录命令、源码状态、耗时、退出码和完整性。Windows 使用 Job Object，在进程启动前建立归属，到时或中断关闭整个进程树。不要把 datagen 的 `--budget-hours` 当成停止机制。

子命令写成裸 `python` / `python.exe` 时，运行器固定使用自身的 Python 解释器，避免 Windows 重新找到系统 Python。显式解释器路径保持原样；报告中的 `requested_command` 和 `command` 分别记录请求与实际执行命令。

超时退出码为 124，中断为 130，其他失败保留非零状态。预算运行器的 `run.json` 必须为 `complete: true`，其子报告也必须完整，才能使用结果；例如被杀死的 datagen 分片或未跑满的门控不能当成完整数据/验收。诊断曲线会周期性保存，超时后可用作部分进展，但不能声明训练完成。

运行器互斥锁拒绝同一预算的并发任务。若终端/运行器被强制关闭，锁和整段时间预留可能保留：先确认没有相关进程仍运行，再人工处理锁；账本保留预留耗时，不通过新建/重置预算来绕过上限。完整性来源于运行器状态，而不是旧的、可能尚未刷新的子报告。

## 工单 15 结论（2026-11-06，已关闭）

两条筛选均完整有效（`complete: true`、`anomaly_counts: {}`、`verify_backend: true`、`cpp_exact: true`），结果都是 **20 局 `0W/0D/20L` / `win_rate=0.0`，`gate.passed=false`**，无合格候选。阶段 4 汇总在 `data/m5/m5_cmp_summary.json`（含全部产物身份）：等算力控制成立（11 个超参逐项相等、各 1600 步、`cap_reached=true`），唯一变量是训练记录数 6,553 vs 204,674。

**支持的结论**：在这一组固定条件下（同一冻结验证集、同一 QAT 配置、固定 1600 次更新、同一 20 局换色筛选开局），追加 20 万条独立数据**未观察到棋力收益**。验证误差口径不唯一：完整 628 条上小数据组 `0.669321` 优于大数据组 `0.685776`，64 样本保真度上大数据组 `0.657575` 优于 `0.666983`，排序不一致，不能据此断言数据收益方向；两组都只把 64 样本常数基线 `0.750735` 降到约 `0.66–0.67`。

**仍未排除的三个并列解释**：数据覆盖不足（103,180 个 D4 轨道、17.82% 饱和标签、无和棋 WDL 类）、全数据下的优化/特征/目标尺度限制（QAT + `--hidden-lr 0.001` 下隐藏层几乎不动）、训练目标与棋力指标不同步。**不得预设网络容量是根因。**

**下一项诊断建议**（新工单，不在此自动执行）：① 量化隐藏层权重的实际更新幅度，确认是否只有输出头在学；② 在同一冻结集 / 同一 1600 步上限下，只改 `hidden_lr` 或标签变换（剔除 ±32767 饱和记录、或改分位数/胜负目标）做单一变量对照；③ 若仍无改善，检查评估分与实际走子选择的相关性。均**不扩网、不加数据、不消耗正式开局**。
