# 02: GUI 完成一局合法对弈

**What to build:** 用户打开 Windows 本地客户端后，可以选择执黑或执白，与现有引擎完成一局有禁手五子棋，查看合法落点、拒绝原因、对局结果并重新开局。该对局使用后续采集和裁判能够共用的权威执行器。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 选择并记录适合本机 C++ 引擎与 Python 训练工具的桌面 GUI 和本地控制方案；提供真实可启动入口。
- [ ] 支持15×15、黑先白后、自由开局、玩家选择颜色、引擎响应、新局及结束后查看着法记录。
- [ ] 客户端通过权威执行器获取完整合法落点、禁手原因、落子结果和终局，不在界面或 Python 裁判另写一套禁手算法。
- [ ] 执行器公开局面重建与校验、合法落点查询、落子和撤销能力，足以供采集、算杀证据复查和比赛裁判复用。
- [ ] 合法落点集合与搜索候选裁剪区分；非法请求和终局后的落子不改变棋盘、行棋方或历史。
- [ ] 对既定规则覆盖三三、四四、真假活三、长连、成五优先、白棋长连、边界与 D4 等价局面，不重新进行产品规则访谈。
- [ ] 没有新模型时明确显示当前使用的现有引擎评估方式，不把手工评估标记为已训练 NNUE。
- [ ] 引擎思考期间界面保持响应；退出或停止对局能够结束相关工作进程，错误在界面明确显示。
- [ ] 用户可从 GUI 完成完整真实对局；着法序列通过同一执行器重放后得到一致结果。

## Verification

在客户端交互与公共执行器边界验证可见行为。复用棋盘、Renju 和协议测试素材，补充非法操作不改状态、终局拒绝落子及完整对局重放。
