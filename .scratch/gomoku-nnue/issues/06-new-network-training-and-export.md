## Verification

复用数据划分、D4、导出文件与整数参考边界。实际运行小样本训练和导出，记录执行结果；验证错误标签契约与模型格式被拒绝。

### 验收记录

**架构与价值契约**

- `trainer/value_model.py`：450 → 1024 → 64 → 32 → 1，单输出（无行棋方分支），参数 529,537；隐藏层为上限固定的 ReLU（默认 8.0），输出 `tanh(z)` ∈ [-1, 1]；从随机初始化开始（种子固定）。
- 特征沿用 `trainer/features.py` 的绝对黑白 450 占位通道（黑 0..224、白 225..449），行棋方**不是**输入；Renju 黑白差异因此保留。
- **价值视角**：训练目标是黑方绝对价值。教师 `teacher-v1` 的记录是行棋方视角，`value_data.record_target` 按行棋方符号转换；`selfplay_result` 记录直接使用黑方绝对结果。网络输出即黑方绝对价值，后续搜索的 negamax 按行棋方取反；该约定写入部署元数据 `value_contract = black-absolute-tanh-v1`。
- 行棋方与棋子计数不一致的样本在数据层被拒绝（`side_to_move` 与黑白子数校验）；样本池本身也强制该一致性。

**训练**

- `trainer/value_data.py` 从 `SamplePool` 读取已提交的冻结 train/validation 划分；验证集按对局身份隔离，并对训练侧做 D4 规范形比对，发现等价局面直接报错而不是训练。
- 八种 D4 空间变换在线增广（每个样本每批随机取一种，只变换空间、不交换黑白）；验证与导出评估不做增广。
- `trainer/value_train.py`：MSE / SmoothL1 可配置；记录种子、步数、批大小、学习率、损失、设备、标签版本、数据身份（样本数、对局数、样本 id 摘要）与架构；样本曝光按 `(完成步数 - 起始步数) × batch_size` 记录。
- checkpoint 格式 `GMVALUE-CHECKPOINT1`：模型/优化器状态、步数、配置、数据身份、架构/规则/特征/价值契约、历史；恢复时校验架构与契约，架构不符的 checkpoint 被拒绝。

**部署格式与整数参考**

- `trainer/value_format.py`：`GMVALUE1`，64 字节头 + JSON 元数据 + 权重体。头与元数据都声明架构、规则（renju）、特征（absolute-color-450）、价值契约、标签版本与训练数据身份；FNV-1a 校验覆盖元数据+权重体。
- 量化：int16 权重 + int32 bias，固定 `ea=9`（1/512），每层一次 `round_div` 移位，激活上限 `act_max_int=4096`；整数参考前向返回定点 z，`value = tanh(z / 512)`（与网络输出同一映射）。
- 拒绝路径实测：旧 `GMNNUE01` 文件、翻转权重体后的校验和、元数据中的旧架构（450-1024-15-2）、架构不符的 checkpoint 全部报错。

**导出保真度（容差先冻结）**

- `value_format.VALUE_TOLERANCE`（训练原模型 vs 整数参考）：mean ≤ 0.010、p95 ≤ 0.030、max ≤ 0.100；`INTEGER_TOLERANCE`（量化权重 float 前向 vs 整数参考）：mean ≤ 0.002、max ≤ 0.010。
- 报告逐项记录实测值、容差与是否通过；不通过时 CLI 返回非零、GUI 显示“未通过”。

**实际执行（真实教师样本）**

- 数据：`tools/collect.py` 真实采集 3 局（depth 3、max-plies 50、sample-every 2、教师预算 150ms、seed 7）→ 46 个候选、10 个有效入池（训练 7 / 验证 3），过滤 `mate 25`、`no_score 9`、`game_over 2`，有效 2.42 样本/秒。
- 训练：120 步、batch 8、lr 1e-3、seed 2、CPU，约 2 秒；训练损失 0.0032，验证损失 0.0484，验证 MAE 0.196。
- 导出：`model.gmvalue` 1,062,082 字节，SHA-256 `232fa16629814b4fc4ec9d052c9b0164ec699e73c9136d966e0f59ace9165885`；元数据架构/规则/特征/价值契约/标签版本/数据身份齐全。
- 保真度：训练原模型 vs 整数参考 mean 0.000326、p95 0.000655、max 0.000655（容差 0.010/0.030/0.100）；量化权重 float vs 整数参考 mean 0.000190、max 0.000269（容差 0.002/0.010）。两项均通过。
- 恢复：从 80 步 checkpoint 继续到 100 步，`start_step=80`，摘要记录来源 checkpoint 与新的数据身份。
- 学习能力核验（合成可学习数据，非棋力）：120 个样本、40 步后验证 MAE 由 0.267 降到 0.216；仅证明链路与优化可运行。
