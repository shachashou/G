# 24: 无饱和候选搜索分排序可学性

**Status:** done（默认配置阴性；后续对照见25）

承接 23 的单变量建议。复用 `t23/full/cases.jsonl`，只保留所有 S4
严格位于 (-32767,32767) 且至少有一个非并列候选对的父局面，不增加数据、
不扩网、不运行棋力筛选或正式门控。标签保持父方视角、越大越好。

## 实验前固定的配置与判据

- seed=42，从零 float 训练，现有网络和优化器，lr=.1 / hidden_lr=.001，
  RankNet，5000 步，每步 128 对，在全部不等分候选对中均匀抽样；无点值项、无增广。
- 按完整 game_id 固定随机划分约 25% 对局留出；移除拟合侧与留出侧父/子局面
  有 D4 等价重叠的整个对局。保存输入 SHA256、父局面 ID、划分与剔除记录。
- 分别报告初始模型、静态 H、最终 float、float16 权重回读 float 推理、
  实际 C++ 整数输出的 macro pair disagreement、tie-adjusted Top-1。
- **拟合成立**：训练侧最终 float disagreement <=.30 且比初始下降 >=.15。
- **导出保真**：训练及留出侧 float16 disagreement 相比 float 退化 <=.01；
  C++ 输出另行判定同一边界，不能用浮点保真替代部署保真。
- **推广信号**：留出侧最终 C++ disagreement <=.35，且比初始下降 >=.10。
  只作工程分流，无因果/棋力保证。拟合、导出、推广三个结论单独报告。
- 这批父局面来自原冻结验证集，任何训练所得权重都标记 diagnostic_only，
  不可交工单 16，不可当 incumbent。若扩大训练，必须重新从训练侧生成候选标签。
- 训练经 budget_run 执行，硬限 600 秒；剩余预算不足时不启动。

## 假设与可证伪预测

1. 干净 S4 排序可学：固定小样本拟合通过上面的阈值；失败则不支持直接扩大数据。
2. 已知 float16 精度足够：回读推理退化不超过 .01；否则精度结论不适用于新标签。
3. 局部记忆难以推广：拟合通过但完整对局留出失败；此时不能宣称标签改善棋力。
4. 最终整数输出压平差距：float16 float 指标保持而 C++ 指标退化；须单独报告。
