# 06: match_runner 对打工具

**What to build:** 配套工具：让两个引擎 build（exe）在相同搜索配置下批量自动对打，输出胜/负/和与胜率统计。它是后续所有迭代（NNUE 换装验收、自举轮次门控）的强度度量基础设施。与 datagen（07）并行无依赖。

**Blocked by:** 04（Alpha-Beta 搜索 + 手工评估）

**Status:** ready-for-agent

- [ ] 支持指定两个引擎可执行文件、对局数、规则模式、先后手交替
- [ ] 开局前若干手随机化（可配置），避免每局雷同
- [ ] 输出胜负和统计与胜率；对局异常（超时、崩溃、非法着法）计为失败并记录
- [ ] 与 06 之前的引擎 build 对打验证工具自身正确性（如 04 vs 02 随机引擎，胜率应为 100%）
- [ ] 结果落盘可复查（每局的着法序列有记录）
