### 2026-11-06 实现与实测

**交付**：`trainer/validation_freeze.py`（`freeze` / `check` 两个子命令 + `canonical_position` / `scan_for_leaks` / `frozen_train_record_ids` 等共享函数）；`dataset.py` 增加 `include_games` / `exclude_games` 与 `MultiBinpackDataset`；`train.py` 增加 `--frozen-validation` / `--train-manifest`；`export.py` 增加 `--frozen-validation`（校准/parity 采样限制在冻结训练侧）；`diagnose.py fidelity` 增加 `--frozen-validation`（评估集合、常数基线、校准样本都来自同一冻结身份，报告 `d4_position_separation_verified`）；`engine/tests/validation_freeze_tests.py` 接入 CTest。

**真实数据实测**（`data/m5/frozen_validation.json`）：按 seed 42 / `val_fraction 0.1` 冻结 28 局 / 628 条验证记录；D4 规范形扫描检出 **9 条**训练侧等价局面，按「隔离整局」规则排除 **1 个整局 / 27 条记录**，验证集合本身不变；训练侧拟合常数在冻结验证集上 MSE `0.780978`、类别先验 CE `0.693117`——与工单 12 的独立诊断（`data/m5/dataset_profile.json`、`qat_splitlr_fidelity`）互相印证。`tools/dataset_profile.py` 用参数化实现复算得到 6,978 个 D4 轨道 / 9 个重叠 / 1,270 个饱和分，与旧画像一致。

**可复核命令**（均已在真实数据上跑通，短任务由 agent 执行）：

```powershell
.venv\Scripts\python.exe trainer\validation_freeze.py freeze --data data\raw\bench-d4\train.binpack --val-fraction 0.1 --seed 42 --out data\m5\frozen_validation.json
.venv\Scripts\python.exe trainer\train.py --data data\raw\bench-d4\train.binpack --frozen-validation data\m5\frozen_validation.json --output weights\m5_frozen_baseline.pt --history data\m5\frozen_baseline_history.json --epochs 2 --batch-size 512 --limit 1000 --seed 42
.venv\Scripts\python.exe trainer\export.py --checkpoint weights\m5_frozen_baseline.pt --data data\raw\bench-d4\train.binpack --frozen-validation data\m5\frozen_validation.json --output data\m5\frozen_baseline.nnue --report data\m5\frozen_baseline_export.json
.venv\Scripts\python.exe trainer\diagnose.py fidelity --data data\raw\bench-d4\train.binpack --checkpoint weights\m5_frozen_baseline.pt --frozen-validation data\m5\frozen_validation.json --probe build\engine\Release\nnue_probe.exe --samples 64 --out-dir data\m5\frozen_fidelity
.venv\Scripts\python.exe trainer\validation_freeze.py check --frozen data\m5\frozen_validation.json --train-data data\raw\bench-d4\train.binpack --out data\m5\frozen_self_check.json --manifest data\m5\frozen_self_manifest.json
```

结构化结果：`frozen_validation.json`（身份/划分/泄漏明细/标签变换/基线）、`frozen_baseline_history.json`（2 epoch，<1 秒）、`frozen_baseline_export.json`、`frozen_fidelity/report.json`（28 个验证对局、C++ scalar/AVX2 逐位一致、`d4_position_separation_verified=true`）。**这些只验证流程可复核，不是棋力候选，也不代表 M5 达标**；2-epoch 基线只用于冒烟。

**边界**：`check` 的清单已把冻结源文件的验证对局从 include 列表移除，跨文件泄漏按局面而非对局编号判定（回归覆盖编号重用）；冻结文件的数据 sha256 不匹配、checkpoint 的冻结身份不匹配、标签变换不一致都会拒绝运行，不静默重建划分。旧 `data/m5/` 报告全部保留为历史。完整 CTest **16/16 全绿**。

**交接给工单 14/15**：新数据落盘后先跑 `tools/dataset_profile.py` 出质量报告，再用 `validation_freeze.py check --frozen ... --train-data <旧> --train-data <新> --manifest ...` 生成训练清单，交给 `train.py --train-manifest`；冻结验证集在整个对照过程中不再重切。
