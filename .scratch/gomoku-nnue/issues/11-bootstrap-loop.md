## Final Model Contract

> 与 `spec.md` 的「最终模型（M6 收敛时冻结）」一致，本工单是它的落地位置。

训练在本项目里是循环内的重复动作，没有单独的「最终训练」阶段：

1. 工单 08 / M4 的 `nnue_v1.nnue` 只验证流水线闭环与跨语言对齐，棋力弱，**不是最终模型**。
2. M5 门控（对 M3 胜率 >65%）通过后，该权重成为第一个有强度意义的**现任权重（incumbent）**。
3. 本工单每轮用现任权重驱动 datagen → 训练 → 导出 → 门控；**新权重胜率达标才晋级**，不达标则现任保持，绝不无条件采用最后一轮产物。

**停止条件**：至少跑满 3 轮且连续 2 轮未晋级（或达到用户设定的轮数 / 时间预算）即判定收敛。此时把当时的现任权重冻结为最终模型，并归档：`weights/final.pt`、`weights/final.nnue`、对应训练 history 与导出 report、各轮门控 JSON、逐轮趋势报告；`weights/final_manifest.json` 记录来源轮次、数据集、seed、门控结果与校验和。产物沿用 `weights/` 的 gitignore 规则，不入库。

- **门控与停止为纯函数、可单测**：`promote_from_gate`（完整 + 门控通过才晋级）、`should_stop`（至少 `--min-rounds` 轮且连续 `--no-promote-streak` 轮未晋级，或达 `--max-rounds`）、`build_final_manifest`（来源轮次 + 数据集 + seed + 门控结果 + sha256 校验和）。
