## 梯度与裁剪证据

只读复核脚本为 `inspect-fit.py`。它检查原数据 hash、按保存的记录索引重建输入，加载最终 checkpoint，不做优化步骤。输出在 `data/m5/fit_inspection.json`，可用以下命令复核：

```powershell
.venv\Scripts\python.exe .scratch\gomoku-nnue\analysis\inspect-fit.py overfit_retry1 overfit_no_quant_reg overfit_mse_only overfit_mse_lr001 overfit_mse_hiddenlr
```

- 默认对照结束时，任务梯度与加权正则梯度夹角余弦：float -0.99609、STE -0.99995，模长也接近。因此总梯度很小不能解释成没有任务学习信号。
- 去掉量化正则后，float 的 MSE 梯度与加权 CE 梯度余弦为 -0.99872。该批 64 个样本有 26 个搜索分符号与最终胜负标签方向不同；这是两种训练目标的折衷证据，不表示 WDL 标签写错。
- 默认 STE 真正量化前向的 L1 非裁剪比例仅约 0.625%；纯 MSE、同一高学习率时约 0.208%。原报告的 `activations_float` 是浮点代理统计，不能替代量化路径；新版另报 `activations_forward`。
- 保持输出学习率 0.1、隐藏学习率 0.001 后，STE 的 L1 非裁剪比例约 53.65%，前层仍有可测梯度，训练 MSE 降到 0.069756。该结果支持继续检查优化设置，而非预先扩大网络。

## 已实现的训练支持

- `train.py` 和 `diagnose.py` 共用 `make_optimizer`，可选 `--hidden-lr` 控制 W0/b0/W1/b1，输出参数保留 `--lr`。默认不变，不传参数仍使用原单组 AdamW。
- QAT 模型以其实际训练的 STE 前向为校准参照；不再朝未取整 master float 重新校准，从而改变训练好的整数输出。float 模型保持原校准行为。fidelity 新增 `trained_forward_vs_final`，区分该指标与 master float 比较。
- 同样本诊断 checkpoint 按 arm 保存 `quant_forward` 元数据；仍标为 diagnostic_only，不能假装独立验证模型。
- CLI 回归验证了分组学习率的实际参数变化、QAT 导出保持训练整数权重、float/STE 元数据。完整 CTest 15/15 通过，25.68 秒；规范与规格两路审查均已完成，唯一元数据问题已修复并复审。

## 结论与边界

默认训练组合在这批固定样本上的拟合受正则、目标牵制及量化路径裁剪影响。保持网络维度/推理格式，训练侧调整已能显著改善同样本拟合；现有证据不支持直接断言容量不足。

这些是训练集拟合结果，不是泛化、输出量化后棋力或 M5 门控通过的证明。纯 MSE 关闭 WDL 目前是有证据支持的候选实验，不是对最终目标设计的永久决定；如独立验证/对打没有收益，需重新评估。浮点与整数仍有差距。
