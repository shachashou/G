# 12: 任务恢复与一站式验收

**What to build:** 用户在同一个 Windows 客户端管理对弈、采集、从零训练、教师训练、自主训练和测评，能够安全暂停、恢复和停止任务，并在重启后继续未完成工作。

**Blocked by:** 10 — 完全无教师自主训练；11 — 增量累加器与推理加速。

**Status:** ready-for-agent

- [ ] GUI 统一提供“玩一把”“收集数据”“从0训练”“自我训练”“测评”和模型选择，显示实际模式及正式、候选版本身份。
- [ ] 长任务均通过公共编排边界运行，界面保持响应；能够查看阶段、有效样本量、池容量、训练进度、资源配置和比赛结果。
- [ ] 任务状态区分运行、暂停中、已暂停、完成、失败和已停止；暂停在安全的数据或训练检查点生效，不仅改变按钮文字。
- [ ] 恢复信息绑定模型与优化器、随机状态、训练进度、样本池提交身份、任务和标签配置；恢复前核验兼容性。
- [ ] 对采集、训练和比赛明确暂停恢复边界；进行中的棋局或评测配对如需重启，明确标记并按原冻结配置重做，不能伪造已完成结果或重复计分。
- [ ] 关闭客户端或显式停止时回收其工作进程；重启后能够从有效状态恢复，不能重复回填胜负、读取半写入数据或重复发布同一候选。
- [ ] 资源配置和并发任务冲突有可见处理，背压与停止条件生效；已提交数据和现任模型不因任务失败受损。
- [ ] 恢复后仍保持验证集、价值契约、模型谱系和评测配置一致；不通过恢复动作重新抽取更容易的验证或比赛数据。
- [ ] 完成小规模真实端到端验收：教师启动得到 v0、实际对弈、持续数据与候选训练、历史测评、完全禁用教师的自主训练、暂停恢复及停止。
- [ ] 最终报告区分链路正确性、数值保真度、性能和棋力证据；没有实际晋级时如实记录，不宣称持续变强。
- [ ] 更新实际安装、启动、任务操作和故障恢复说明，使新环境用户可以在本地运行交付工作台；不把尚未实现的按钮写作已可用。

## Verification

以 GUI 可见操作和公共任务编排为最高验收边界，补充重启、中断、依赖缺失、数据不完整和恢复配置不符场景。外部可观察结果与持久状态相互核对。
