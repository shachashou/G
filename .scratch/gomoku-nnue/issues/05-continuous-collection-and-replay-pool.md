# 05: 持续采集与滚动样本池

**What to build:** 用户从客户端启动采集后，系统持续产生多样合法局面、筛选打标并写入有容量上限的训练样本池，可查看有效吞吐、过滤、去重和留存状态。

**Blocked by:** 04 — 教师评分与有效样本落盘。

**Status:** ready-for-agent

- [ ] 使用明确的采集策略与版本身份自动产生多样开局和中盘，复用权威规则、战术筛选和教师适配；无需已训练的新模型即可生成启动数据。
- [ ] 按可追溯对局或采样来源提交完整数据；未提交、未校验或半写入分片不能被训练者读取。
- [ ] 样本池容量、启动样本量、新旧混合策略、探索配置及采集速率可配置，并记录本次运行的实际值。
- [ ] 按明确策略去重、控制重复并逐步淘汰旧数据；正在读取的分片不被原地删除，采集过快时有背压或暂停。
- [ ] 对局级验证身份独立冻结，检查 D4 等价局面泄漏；追加和淘汰训练数据均不改变验证成员。
- [ ] 数据契约能够承载教师标签和后续自主对局结果，按来源区分并允许只存在其中一种有效监督，不在本工单提前实现自主训练。
- [ ] 分别显示累计生成、有效、去重后有效、当前池容量、过滤原因和有效样本每秒；不把对称增广计为独立原始数据。
- [ ] 少量有效数据即可供下游读取，不设置必须先收集数百万条的限制。
- [ ] 在小容量配置下完成真实采集、入池、读取与淘汰演示，停止后不遗留采集和教师进程。

## Verification

在采集任务与样本池读写公共边界验证完整性、容量、并发读取和淘汰、重复控制及防泄漏。小规模实测报告有效吞吐，不外推为最终棋力结论。
