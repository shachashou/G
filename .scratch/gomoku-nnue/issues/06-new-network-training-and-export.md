# 06: 新网络从零训练与导出

**What to build:** 用户从客户端选择一批有效教师样本，从随机初始化训练指定网络，查看训练与验证指标，并获得可校验的 checkpoint、部署模型和导出保真度报告。

**Blocked by:** 01 — 训练基础脱离旧实验；04 — 教师评分与有效样本落盘。

**Status:** ready-for-agent

- [ ] 网络为450 → 1024 → 64 → 32 → 1，单输出；绝对黑白占位通道保留 Renju 角色差异，不偷偷恢复旧隐藏层或双输出头。
- [ ] 与打标契约共同冻结特征、价值视角、归一化和输出映射；行棋方与合法棋子计数一致，后续 negamax 转换有明确约定。
- [ ] 支持 MSE 与 SmoothL1，记录随机种子、训练配置、实际优化步数、样本曝光、标签身份及模型架构。
- [ ] 实现八种 D4 空间变换的在线训练增广，不交换黑白；验证按对局和 D4 等价身份隔离。
- [ ] 能从已提交的小批量数据训练，不以滚动池或百万条数据作为前置依赖；后续可复用同一训练能力接入样本池。
- [ ] GUI 发起真实训练并展示进度、训练误差、独立验证误差及失败信息，后台计算不阻塞界面。
- [ ] checkpoint 保存训练状态及来源身份，能作为下一阶段候选训练与恢复的输入；从零训练明确采用随机初始化。
- [ ] 新架构使用可识别的新部署格式或版本，包含规则、特征、价值契约与校验身份；拒绝按新布局解释旧权重。
- [ ] 导出模型回读成功，并分别比较训练原模型、量化导出模型及整数参考前向；先记录并冻结合理容差，再判断保真度是否通过。
- [ ] 小规模真实训练与导出闭环完成；仅证明可运行和数值表现，不把损失下降称作棋力晋级。

## Verification

复用数据划分、D4、导出文件与整数参考边界。实际运行小样本训练和导出，记录执行结果；验证错误标签契约与模型格式被拒绝。
