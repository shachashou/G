# Build toolchain: everything needed to build the C++ engine and the Rust VCF
# bridge lives inside the venv on Windows.
#   * cmake / ctest / ninja / ziglang are PyPI wheels (ziglang bundles clang,
#     libc++, lld and the mingw-w64 headers/libraries the build targets).
#   * the Rust toolchain is installed *into* .venv once with
#     `.venv\Scripts\python.exe tools\build\bootstrap_toolchain.py`
# No system cmake, Visual Studio, Windows SDK or global ~/.cargo is used.
# On Linux/macOS the system C++ compiler and Rust toolchain are used.
#
#   py -3.12 -m venv .venv
#   .venv\Scripts\python.exe -m pip install -r requirements.txt ^
#       --extra-index-url https://download.pytorch.org/whl/cu124
#   .venv\Scripts\python.exe tools\build\bootstrap_toolchain.py
#   .venv\Scripts\python.exe tools\build\build.py --clean
#
# The +cu124 torch wheel is the CUDA build for this machine's RTX 4080 SUPER.
# On a CPU-only machine replace that line with `torch==2.6.0`; the training
# scripts auto-select CUDA when available and stay fully functional on CPU.
