# 07: 使用新模型实际对弈

**What to build:** 用户在客户端选择新导出的模型后，C++ 引擎真实使用该模型和 Alpha-Beta 搜索完成合法对局。先建立全量重建的正确性参照，为自主对弈和后续增量加速提供可用部署路径。

**Blocked by:** 06 — 新网络从零训练与导出。

**Status:** ready-for-agent

- [ ] C++ 加载新架构和格式，检查完整性、规则、特征及价值契约；损坏或不兼容模型明确失败。
- [ ] 实现新网络标量前向和全量第一层重建，作为后续增量与 SIMD 的长期数值参照。
- [ ] 对同一量化模型与 Python 整数参考完成对拍，训练原模型与 C++ 部署结果按冻结容差检查导出保真度。
- [ ] 价值按约定转换到当前行棋方搜索视角；终局和已证明战术结果保持独立语义，不能被普通网络分数覆盖。
- [ ] 新模型接入实际 Alpha-Beta 选点，终局、合法落子、开源 VCF 及时间控制共同生效。
- [ ] GUI 显示实际加载的模型身份及评估方式；新候选可试玩，但不会因为加载成功自动晋级。
- [ ] 没有模型或加载失败时，不静默切换手工评估并继续把结果标为 NNUE。
- [ ] 新模型在客户端及无界面进程路径均能完成真实对局；从着法记录重放获得相同终局结果。
- [ ] 当前交付不依赖增量优化工单，允许使用全量参照推理先跑通自主对弈的必要基础。

## Verification

通过既有推理对拍边界与真实引擎协议验证模型身份、正负视角、格式拒绝、时间控制和完整对局；GUI 验证模型选择到落子的可见路径。
