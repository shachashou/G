工单 07 完成，验收记录：

- **格式契约**：`tools/README.md` 是权威格式文档；C++ 写端 `engine/src/binpack.h/.cpp`，Python 读端 `trainer/binpack.py`（纯标准库 + `mmap`）。文件为 64 字节头（magic `GOMOKU07` + version 1 + depth/VCF/TT/规则/种子/计数）+ N 条 64 字节记录：黑 225 bit（29 字节）+ 白 225 bit + `int16` 搜索分 + flags（WDL 2 bit / 行棋方 / game-start / game-end）+ `u8` ply + `u16` 实走着法。全 little-endian，`static_assert` 钉死 64 字节；头里 magic/version/尺寸/搜索配置不符一律拒绝读取。WDL 以行棋方为准（0 负 / 1 和 / 2 胜 / 3 未回填）；引擎 `int` 分数（mate ±999999、棋形表峰值 500000）统一饱和到 `±32767`，`-32768` 保留不用，`tanh(score/400)` 下不损失训练信号。`Record.feature_indices()` 直接给出 450 维颜色绝对特征索引，供 08 的 DataLoader 复用。
- **结果回填**：worker 先写占位头（计数 0）并把每条记录以 `WDL=3` 顺序落盘、记下偏移；对局结束时按每条记录的 `stm` 把绝对胜负换算成 WDL，随机写回该记录 `+60` 的 flags 字节并置首/末记录的边界位，最后回写头部计数。占位头因此也是崩溃检测哨兵（计数与文件大小不符会被 `validate` 抓到）。game-start/game-end 位让「验证集按对局划分」不依赖 ply 单调性。
- **自我对弈与并行**：`datagen.exe` 单进程单分片单 RNG 流；`tools/datagen.py run` 用 `subprocess` 拉起 N 个互不共享状态的 worker（各自 `--seed` / `--shard-id` / shard 文件 / 日志），`merge` 校验各分片头一致后只拼记录体、重写单一头（累加记录/对局数）。开局前 3 手在中心 7×7 内按 `Evaluator::moveHeuristic` 做 softmax 温度采样（`--opening-temp`，0=贪心，越大越平；默认 1.0），用 `isPlayable` 过滤禁手；这 3 个局面不记录。此后每步 `Search::findBestMove` 固定深度、无时钟，搜索前 `Search::reset()` 清空 TT/启发式，使分数只依赖「局面 + depth + VCF + TT 大小」。
- **复盘校验**：`datagen.exe --verify` 从两个 bit plane 复原棋盘（含行棋方/ply/走子合法性校验），按文件头配置重新搜索并与 `encodeScore` 比较；`tools/datagen.py verify` 封装之。`validate` 全量检查 magic、64 字节布局、padding/保留位、两平面不重叠、ply=子数、stm=ply 奇偶、着法合法、WDL 与整局结果一致、边界位与头部计数。实测 280 局 / 7208 条记录全量 `validate` 零错误；抽查 64 条零差异；`shard_0000` **210/210 条全量复盘零差异**；篡改任一条分数会被 `--verify` 以非零码检出。
- **吞吐实测与预案**（本机 28 逻辑核，Release/AVX2；口径为墙钟时间内落盘局面数）：单 worker depth 6 = 2.2 局面/秒；16 进程 depth 6 = 3.2 局面/秒（1000 万约 870 小时，且不同开局耗时方差极大，最慢 worker 258 秒拖垮整批）；16 进程 depth 5/4 = 43.5 / 90.9；28 进程 depth 5/4 = 94.2 / 171.8；**28 进程 × 10 局/进程 × depth 4 = 285.2 局面/秒 → 1000 万约 9.74 小时**，满足 12 小时预算（门槛 231.48 局面/秒）。depth 3 = 2187 局面/秒但棋力过弱，仅作应急兜底。置换表 16/64MB、VCF 节点上限 500/5000 的对比实测对耗时无实质影响（瓶颈是每个节点为所有候选点跑 Renju 禁手判定）。因此按工单预案启用「降 depth 到 4 + 并行度从 16 提到 28」，`--depth` / `--workers` / `calibrate` 保留可重测。完整表格与建议写入 `tools/README.md` 与 `manifest.json`。
