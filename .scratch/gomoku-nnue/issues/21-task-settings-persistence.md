# 21: 训练任务参数持久化

**What to build:** 自我训练/教师训练的任务预算（最多采集局、轮数、步数、学习率、样本量、并发、开局对数、自对弈时间与探索率、输出目录、设备与模式）**所见即所得**：改动立即生效并在 300 ms 内自动保存，没有单独的「保存」按钮；关闭客户端前也会强制落盘。

**Blocked by:** 20 — 训练任务导出拒绝可见性。

**Status:** done

- [x] `TrainingTaskPanel` 接受可注入的 `QSettings`（主窗口传入同一份客户端设置）。
- [x] **所见即所得**：所有任务参数控件（含输出目录、设备、模式）变化后启动 300 ms 防抖定时器自动保存，无需点任何按钮。
